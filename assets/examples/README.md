# 示例库

三套成品风格，都满足 `SKILL.md` 里那六条约束。

| | 名字 | 用于 |
|---|---|---|
| 01 | **暗绿深红** · Dark Green & Crimson | 画**结构**：流程、分栏、数据图 |
| 02 | **浅红浅蓝** · Pale Red & Blue | 画**东西**：物理过程、装置、人体、实验对比 |
| 03 | **渐变蓝** · Gradient Blue | 画**数据**：多面板论文图、系列多、需要明度区分的图表 |

**这三套是成品，配色就是它们的一部分。** 点名要哪个风格，就连配色一起用。
只想借结构、配色换自己的，走 `SKILL.md` 第八节重新定参数。

---

## 01 · 暗绿深红

白底 + 1px 发丝线 + 宋体 + 暗绿主色 + 深红强调 + 金色短横线。没有具象主体，全靠排版本身立住。

色值：`#053D3E` 暗绿 / `#A5271B` 深红 / `#3E7A6E` 石绿 / `#B9914E` 金

| 文件 | 示范什么 |
|---|---|
| `01-loop.png` | **环形关系图**。五个节点用同款空心圆，只靠描边色和位置区分；中心用实心块放主标签；环形箭头表达顺序 |
| `02-segments.png` | **分栏不画盒子**。五栏并列，靠一条通栏细线 + 列间发丝线分隔；顶部三色横条表达层级归属 |
| `03-donut.png` | **环形数据图**。中心放最大那个数字，右侧图例同类项同字号；无网格、无边框 |
| `04-line.png` | **折线图**。所有横线等距、同粗细、同色；标签统一放点的上方或下方，白色描边避免和网格线糊在一起 |

## 02 · 浅红浅蓝

浅色块填区域 + 墨黑器件轮廓 + 一点红做强调。有具象主体，靠形状和少量颜色区分。

色值：`#D5EEFD` 浅蓝 / `#FBDDD8` 浅红 / `#1A1A1A` 墨 / `#EA2A2E` 强调红

| 文件 | 示范什么 |
|---|---|
| `01-water-pathway.jpg` | **颜色只表达对立**。全图唯一的红是那条"旁路"，其余全是浅蓝与墨黑，读者一眼知道问题在哪 |
| `02-electrodes.jpg` | **并列方案不画卡片**。三个方案直接并排，浅蓝填充表达区域，器件一律墨黑轮廓，没有任何边框 |
| `03-physical.jpg` | **写实主体 + 极简标注**。大面积浅蓝表达水体，箭头和文字是唯一的彩色信息 |

## 03 · 渐变蓝

白底 + 极浅网格 + 蓝色**单色阶**填系列 + 细边框多面板。数据密集的论文/报告图用它。

色阶：`#006090` 深 → `#3080C0` 中 → `#90D0F0` 浅 → `#E0E0F0` 淡

| 文件 | 示范什么 |
|---|---|
| `01-multipanel.png` | **2×2 多面板**。子图标 (a)(b)(c)(d)，各自独立轴；同一色相靠明度区分不同系列，不换色相 |
| `02-seasonal-grid.png` | **同构多图**。四个季节用完全相同的轴范围和版式，便于横向对比；虚线区分第二量纲 |
| `03-stacked-bars.png` | **堆叠柱 + 直接标注**。每段数值直接标在柱上，不用图例猜；底部类别标签两行（名称 + 缩写） |
| `04-error-lines.png` | **双指标折线**。实线/虚线区分两个指标，关键点直接标数值和名称，不做图例对照 |

**这套的关键**：系列再多也只用**一个色相**，靠明度分远近；网格线压到几乎看不见；数值直接标在图形上，不靠图例。

## 怎么用

1. **先选风格**：画结构 → 01；画东西 → 02；画数据 → 03
2. **找结构最接近的那张**：不是找颜色最像的
3. **拆它的结构**：层级几级？线用在哪？间距多少？标签怎么放？
4. **重画**：选定的风格，配色跟它走；要换配色就按第八节重新定
