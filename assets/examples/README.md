# 示例库

两套风格，都满足 `SKILL.md` 里那六条约束。

**看结构，别抄配色。** 层级怎么分、细线用在哪、留白多少、标签怎么避让——只有这些是可迁移的。
颜色、字体、圆角是随项目走的参数。

---

## 01 · 素白细线

**白底 + 1px 发丝线 + 宋体 + 三色层级 + 大留白。**

适合：文档内页要印刷的版面、以文字和结构为主的图（流程、分栏、数据图）。
没有具象主体，全靠排版本身立住。

| 文件 | 示范什么 |
|---|---|
| `01-loop.png` | **环形关系图**。五个节点用同款空心圆，只靠描边色和位置区分；中心放主标签；环形箭头表达顺序 |
| `02-segments.png` | **分栏不画盒子**。五栏并列，靠一条通栏细线 + 列间发丝线分隔；顶部的色带表达层级归属 |
| `03-donut.png` | **环形数据图**。中心放最大那个数字，右侧图例同类项同字号；无网格、无边框 |
| `04-line.png` | **折线图**。所有横线等距、同粗细、同色；标签统一放点的上方或下方，白色描边避免和网格线糊在一起 |

## 02 · 淡彩示意

**浅色块填区域 + 墨黑器件轮廓 + 一点红做强调。**

适合：要画"东西"的示意图——物理过程、装置结构、人体、实验对比。
有具象主体，靠形状和少量颜色区分，不靠文字堆。

| 文件 | 示范什么 |
|---|---|
| `01-water-pathway.jpg` | **颜色只表达对立**。全图唯一的红是那条"旁路"，其余全是浅蓝与墨黑，读者一眼知道问题在哪 |
| `02-electrodes.jpg` | **并列方案不画卡片**。三个方案直接并排，浅蓝填充表达区域，器件一律墨黑轮廓，没有任何边框 |
| `03-physical.jpg` | **写实主体 + 极简标注**。大面积浅蓝表达水体，箭头和文字是唯一的彩色信息 |

## _reference · 同一约束的其他参数

| 文件 | 说明 |
|---|---|
| `01-glass.png` | 玻璃卡片：磨砂半透明面板、圆角 28px、银灰柔光背景、无衬线 |
| `02-handdrawn.png` | 黑白手绘：行楷标题、楷体正文、用 SVG 滤镜做手抖线条 |

同一份内容，两种完全不同的参数。放这两张是为了说明：**约束不变，参数可以完全换**。
它们**不算独立风格**，只是参数取值不同的例子。

---

## 怎么用

1. **先选风格**：这张图要画"结构"还是画"东西"？结构 → 01；有具象主体 → 02
2. **找结构最接近的那张**：不是找颜色最像的
3. **拆它的结构**：层级几级？线用在哪？间距多少？标签怎么放？
4. **用自己项目的参数重画**：颜色、字体、圆角都换成项目自己的

没有合适的参考，就按 `SKILL.md` 第八节那五步重新定参数，别硬套这两套。
