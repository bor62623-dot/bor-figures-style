# 示例库

**看结构，别抄配色。**

这些图是「简约高级」的实例，不是模板。它们满足 `SKILL.md` 里那六条约束，但**颜色、字体、圆角半径各不相同**——那些是随项目走的参数。

看的时候问自己：**它的层级是怎么分的？细线用在哪？留白留了多少？标签怎么避让的？**
不要问：**它用了什么颜色？**

---

## document/ —— 白底发丝线

文档配图。纯白底、1px 细线做结构、宋体、大字号。来自一份非遗品牌策划书。

| 文件 | 示范什么 |
|---|---|
| `01-loop.png` | **环形关系图**。五个节点用同款空心圆，只靠描边色和位置区分；中心放主标签；环形箭头表达顺序 |
| `02-segments.png` | **分栏不画盒子**。五栏并列，靠一条通栏细线 + 列间发丝线分隔；顶部用三色横条表达层级 |
| `03-donut.png` | **环形数据图**。中心 52px 大数字，右侧图例同类项同字号；没有网格、没有边框 |
| `04-line.png` | **折线图**。六条横线等距同粗细同色；标签统一放点的上方/下方，白色描边避免与网格线糊在一起 |

## diagram/ —— 蓝红信息图

示意图与数据图。蓝 = 正常 / 信息流向，红 = 问题 / 异常，**红只做线、标签和小段波形，不铺面**。

| 文件 | 示范什么 |
|---|---|
| `01-water-pathway.jpg` | **颜色只表达对立**。全图唯一的红是那条"旁路"，其余全是蓝与墨黑；读者一眼知道问题在哪 |
| `02-electrodes.jpg` | **并列方案不画卡片**。三个方案并排，浅蓝填充表达区域，器件一律墨黑轮廓 |
| `03-solution-map.jpg` | **二维定位图**。只用位置和文字标签，四象限靠一条虚线十字划分，不填色块 |
| `04-physical.jpg` | **写实主体 + 极简标注**。大面积浅蓝表达水体，箭头和标签是唯一的彩色信息 |
| `05-signal-chain.jpg` | **横向链路**。方框串成一条线，几乎不上彩，靠箭头方向和字号表达流程 |
| `06-amp-compare.jpg` | **三联数据面板**。纵轴各自独立，柱与误差棒同色，只留左/下轴线，无网格 |
| `07-framework.jpg` | **纯黑白也能分栏**。流程条完全不用颜色，靠字号、箭头和留白分层 |

## variants/ —— 同一约束，不同参数

同样一份内容（三方协同模式），两种完全不同的参数实现：

| 文件 | 参数 |
|---|---|
| `01-glass.png` | 玻璃卡片：磨砂半透明面板、圆角 28px、银灰柔光背景、无衬线字体 |
| `02-handdrawn.png` | 黑白手绘：行楷标题、楷体正文、`feTurbulence` 制造手抖线条 |

这两张的存在是为了说明一件事：**约束不变，参数可以完全换**。
白底发丝线和玻璃卡片看着像两套东西，但它们满足的是同一套六条约束——都做了减法、都靠对比拉层级、都没有多余装饰。

## 怎么用这些示例

1. **先确定约束**：这个版面要满足哪几条？缺哪条？
2. **找结构最接近的那张**：不是找颜色最像的
3. **拆它的结构**：层级几级？线用在哪？间距多少？标签怎么放？
4. **用自己项目的参数重画**：颜色、字体、圆角都换成项目自己的
